Only official conversion tables go here, copied by hand from the source, with the URL and the
date you copied it in the file. Example for WES (percentage scale):

    # data/conversion_tables/wes_percentage.yaml
    source: <official WES URL>, copied 2026-11-21 by <name>
    bands:
      - {min: <lowest % for this band>, gpa: <US GPA>}

If a table is missing, the rule engine answers "insufficient information" instead of guessing.
